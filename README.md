# AI-Based Network Intrusion Detection System

This project detects network intrusions using Machine Learning.
It uses a Random Forest classifier and a Streamlit web interface
to classify network traffic as normal or intrusion.

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- NumPy
- Pandas

## How to Run
1. Install dependencies:
   pip install streamlit scikit-learn numpy pandas
2. Run the app:
   streamlit run nids_main.py
